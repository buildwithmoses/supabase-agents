## Passwords
Reset your password from the sign-in screen with Forgot password.

## Two-factor authentication
Turn on two-factor authentication in Settings > Security using an authenticator app. Courtline does not send login codes by SMS.

## Sessions
You stay signed in for 30 days on each device.
